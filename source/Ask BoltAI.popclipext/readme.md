# Ask BoltAI

Select text in another app, then choose Ask BoltAI in PopClip. BoltAI opens Instant Chat with the selection as an editable attachment. Add a question and press Send. The action does not send a message automatically.

Requires BoltAI 2.17.0 or later and PopClip 2026.8.1 or later.

If you have both BoltAI editions installed, use the extension's **Open with** setting in PopClip to choose the website or Setapp app. The default uses macOS's `bolt://` handler.

## Privacy

The extension passes selected plain text to BoltAI on your Mac. It makes no network request itself. If you press Send, BoltAI may send the text to the AI provider selected for Instant Chat.
