# BoltAI Workflows

Select text in another app, then choose BoltAI Workflows in PopClip. BoltAI opens your workflow picker with that selection. Pick a workflow to use its saved prompt, model, preview, and output settings. Nothing runs until you choose a workflow.

Requires BoltAI 2.17.0 or later, PopClip 2026.8.1 or later, and Accessibility permission for AI Workflows in BoltAI. Direct output depends on the source app accepting replacement text.

If you have both BoltAI editions installed, use the extension's **Open with** setting in PopClip to choose the website or Setapp app. The default uses macOS's `bolt://` handler.

## Privacy

The extension passes selected plain text to BoltAI on your Mac. It makes no network request itself. When you run a workflow, BoltAI may send that text to the AI provider selected for the workflow.
